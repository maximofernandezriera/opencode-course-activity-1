### 1. Comportamiento y Semántica (estilo `wc`)

#### 1.1 Opciones principales
* `-l`, `--lines`: Cuenta saltos de línea (`\n`).
* `-w`, `--words`: Cuenta palabras delimitadas por espacios en blanco.
* `-m`, `--chars`: Cuenta caracteres (soporte Unicode).
* *(Opcional / Recomendado)* `-c`, `--bytes`: Cuenta bytes (en `wc` original, el conteo por defecto suele ser bytes, pero podemos soportar `-m` y `-c`).

#### 1.2 Comportamiento por defecto
* Si el usuario **no especifica ningún flag** de conteo: se activan automáticamente **líneas**, **palabras** y **caracteres** (o bytes).
* Si el usuario pasa uno o varios flags específicos (ej. `-l` o `-lw`): se muestran **únicamente** las métricas solicitadas.

#### 1.3 Entradas soportadas
* **Uno o más archivos**: `wordcount archivo1.txt archivo2.txt`
* **Entrada estándar (stdin)**: Si no se pasan archivos o si se especifica `-`, lee desde `sys.stdin` (ej. `cat file.txt | wordcount`).

#### 1.4 Formato de salida y totales
* Orden canónico de columnas: `líneas  palabras  caracteres  [nombre_archivo]`.
* Si se procesan **2 o más archivos**, al final se agrega una línea `total` con la suma acumulada de cada métrica.
* Alineación tabular a la derecha (espaciado uniforme, tal como hace `wc`).

#### Estructuras de datos (`core.py`)
```python
from dataclasses import dataclass
from typing import BinaryIO, TextIO

@dataclass
class Stats:
    lines: int = 0
    words: int = 0
    chars: int = 0
    bytes_count: int = 0

    def add(self, other: "Stats") -> "Stats":
        return Stats(
            lines=self.lines + other.lines,
            words=self.words + other.words,
            chars=self.chars + other.chars,
            bytes_count=self.bytes_count + other.bytes_count,
        )
```

#### Consideración de rendimiento
* Para archivos grandes, procesar por **chunks / streams** en lugar de leer el archivo completo en memoria (`read()` completo puede consumir demasiada RAM).
